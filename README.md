# CareerCopilot

CareerCopilot is a bilingual English and Chinese AI career assistant web app for international students seeking jobs abroad.

## Tech Stack

- Next.js 14 App Router
- TypeScript
- Tailwind CSS
- shadcn/ui-style components
- next-intl

## Run Locally

```bash
npm install
npm run dev
```

Open http://localhost:3000/en.

## Useful Scripts

```bash
npm run typecheck
npm run build
```
